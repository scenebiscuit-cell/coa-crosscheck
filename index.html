How it works

A reader turns the COA into structured fields: the built-in parser, or an AI model if you connect one. Then plain code applies the selected state's rules. The same COA always gets the same verdict, and you can correct any value the reader got wrong.

Which limits apply

Where a state publishes its own contaminant limits, the checker uses them and flags labs that printed looser limits than the state's. Where a state doesn't, results are compared to the limits printed on the COA.

Run with a local model

1. Install Ollama and run ollama pull qwen2.5:14b. For scanned COAs and photos, also pull qwen2.5vl:7b.

2. Let this site talk to Ollama. On Windows, run setx OLLAMA_ORIGINS "https://your-site" in PowerShell, then quit Ollama from the system tray and start it again.

3. Open Use a local AI model above and click Connect. If your browser asks to let the site reach apps on this device, allow it.
